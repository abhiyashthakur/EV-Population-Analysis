# EV-Population-Analysis

Comprehensive analysis and visualization of Electric Vehicle population data using Python, Pandas, Matplotlib, and Seaborn.

## 📊 Project Overview

This project analyzes Electric Vehicle (EV) population data to uncover trends in EV adoption, manufacturer distribution, geographic patterns, and vehicle characteristics. The analysis provides insights into the growing electric vehicle market.

## 📁 Dataset

The analysis uses the Electric Vehicle Population dataset from Washington State Open Data Portal, containing information about battery electric vehicles (BEVs) and plug-in hybrid electric vehicles (PHEVs) registered in Washington State.

## 🔍 Analysis Performed

1. **Vehicle Type Distribution** - Analysis of BEV vs PHEV adoption
2. **Manufacturer Analysis** - Top EV manufacturers and their market share
3. **Model Popularity** - Most popular EV models in the dataset
4. **Temporal Trends** - EV registration trends by model year
5. **Electric Range Analysis** - Distribution and statistics of vehicle range
6. **Geographic Distribution** - EV adoption by county and city
7. **CAFV Eligibility** - Clean Alternative Fuel Vehicle qualification analysis

## 📈 Key Findings

- **BEVs dominate** the market over PHEVs
- **Tesla** is the leading EV manufacturer
- **Urban areas** show higher EV adoption rates
- **Electric range** is improving with newer models
- Majority of vehicles qualify for **clean energy incentives**
- Year-over-year growth in EV registrations

## 📦 Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/EV-Population-Analysis.git
cd EV-Population-Analysis
```

2. Install required packages:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## 🚀 Usage

1. Open the Jupyter Notebook:
```bash
jupyter notebook EV_Population_Analysis.ipynb
```

2. Run all cells to reproduce the analysis

3. The notebook will automatically download the dataset or create a sample dataset if download fails

## 📊 Visualizations

The project includes various visualizations:
- Bar charts for categorical distributions
- Pie charts for percentage breakdowns
- Line plots for temporal trends
- Histograms and box plots for range analysis
- Horizontal bar charts for geographic comparisons
